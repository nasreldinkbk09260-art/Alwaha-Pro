# Alwaha-Pro 3.0.2 — R7.4 Release Candidate

هذه الحزمة امتداد مباشر لفرع R7.3 عند commit `553e1c431a0cfb92112516533b746ba0a2976f4f`؛ لم نبدأ من الصفر ولم نرجع إلى خط قديم. النسخ 2.8.5–2.8.8 محفوظة كمراجع تاريخية للميزات، مع بقاء هوية التطبيق الحالية.

## أهم ما أضيف في R7.4

- مدخل مستقل لمحادثات السوق بجانب أزرار الشراء والبيع و«سلعي»، مع شاشة كاملة للمحادثات والرسائل.
- عزل طبقات الصفحات المفتوحة عن الخلفية: `inert`، حصر التركيز، زر الرجوع وإغلاق الطبقة الأعلى أولاً.
- دوائر تنقل شفافة منفصلة، يمكن تغيير موضعها وترتيبها وإخفاؤها واستعادتها، مع سحب يبدأ بعد ضغط مطول، ومقبض إظهار عند فتح الصفحات.
- أربعة ثيمات بخلفيات محلية بدلاً من واجهة الفصول: الكون، الشفق والطبيعة، أعماق المحيط، وضوء القمر. أبعاد الأصول الحالية 600×600 وترقيتها إلى HD ما زالت ضمن الموانع المفتوحة.
- الاحتفاظ بمزايا السوق المستقلة، التنبيهات، الأرشيف والضمان، الخزنة المشفرة، غرفة الأطفال المحلية، المكالمات، والألعاب؛ لا يستعاد خيار الشبكة المحلية.
- إصلاح فحص تكرار معرف الفيديو الديناميكي بتحويله إلى data attribute واحد يخدم نافذة الكاميرا وتسجيل الريلز دون ID مكرر.

## ما تحقق في بيئة العمل

جميع اختبارات npm الساكنة الاثني عشر نجحت بعد التعديلات، وكذلك فحوص صياغة JavaScript/JSON/Shell وتفرد 184 معرّفاً ثابتاً في HTML. هذا لا يثبت تشغيل المتصفح الفعلي أو نجاح البناء من مصدر R7.4؛ CI يجب أن يعيد بناء Web/APK/AAB على SHA الجديد.

## طريقة رفع المصدر

بعد فك ZIP في Termux، افتح مجلد المصدر وشغّل:

```bash
bash ./TERMUX-PUSH-3.0.2-R7.4-20261102.sh
```

السكريبت ينشئ فرعاً مستقلاً من commit R7.3، ويرفض استبدال فرع R7.4 إن كان موجوداً. لا يرفع إلى `main`، ولا ينشر الموقع، ولا يطبق migrations، ولا يشغّل `supabase db push`.

## موانع النشر الرسمي

هذه الحزمة **Release Candidate Source** وليست بعد «النسخة الرسمية الكاملة». لا تزال مصالحة سجل migrations الإنتاجية (بما فيها ملفان تاريخيان مفقودان)، وتفعيل Leaked Password Protection، ومراجعة وظائف `SECURITY DEFINER`، واختبار السوق والإشعارات والمكالمات على هاتفين وشبكتين، والتحقق من الاستعادة والحرارة/الصوت، بوابات غير مغلقة. راجع `docs/RELEASE-BLOCKERS-AR.md`.

Build #48 على GitHub يخص R7.3 وليس واجهة R7.4؛ لا تستخدم ملفاته باعتبارها بناء R7.4.
