# Alwaha-Pro 2.8.5

تطبيق اجتماعي عربي مبني على Capacitor وSupabase، يتضمن الرئيسية والمنشورات والتعليقات والإعجابات، السوق، الريلز، الرسائل المباشرة، دليل الأعضاء، طلبات الصداقة، المتابعة، غرف الألعاب الجماعية، الملف الشخصي والإعدادات.

## إعداد إصدار 2.8.5

- معرّف Android: `pro.alwaha.app`.
- الأيقونة الرسمية: `icon.png` (تُحفظ كما هي).
- البريد ورقم الهاتف اختياريان عند التسجيل. التسجيل دون بريد يعتمد على اسم مستخدم وكلمة مرور من خلال Edge Function `username-auth`.
- متابعة الأعضاء تعتمد على جدول `public.follows` وسياسات RLS الخاصة به.
- المكالمات تستخدم WebRTC وSupabase Realtime؛ TURN اختياري ويحتاج بيانات مزوّد صالحة.
- الرنة الأصلية مولّدة داخل التطبيق، وليست أغنية محمية بحقوق نشر.

## نشر الخادم قبل الاستخدام العام

يلزم أولًا مطابقة سجل ترحيلات Supabase مع المستودع؛ لا تشغّل `supabase db push` حتى تُحلّ كل الفروقات. بعد ذلك راجع migration `20261014090000_username_follows_call_features.sql` وانشر `username-auth` و`call-config`. لا تُضمّن مفتاح Service Role في تطبيق العميل.

## معايير قبول الإصدار

نجاح GitHub Actions وحده لا يُثبت عمل الحسابات والمحادثات والمكالمات على هاتفين. قبل الإعلان عن الإصدار العام، اختبر حسابين منفصلين: التسجيل بالبريد وبدونه، الدخول، ظهور الملفات الشخصية، طلب وقبول الصداقة، المتابعة وإلغاؤها، الرسائل ثنائية الاتجاه الفورية، مكالمة واردة وصادرة، الإذن بالميكروفون، وإعادة فتح التطبيق.

Bluetooth الحقيقي والمكالمات أثناء إغلاق التطبيق بالكامل غير مدعومين في هذا الإصدار.
