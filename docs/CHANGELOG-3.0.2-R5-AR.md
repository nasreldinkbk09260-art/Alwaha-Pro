# سجل تغييرات Alwaha-Pro 3.0.2 — R5

- استرجاع ومراجعة حزم تاريخية 2.8.2 و2.8.4 و2.8.7 و2.8.8 وتحديث مقارنة الميزات حتى 2.8.2.
- استعادة لوحة الإدارة الأساسية وEdge Function `admin-api` من النسخة المنشورة (ACTIVE v5)، وإضافة شاشة سجل التدقيق وworkflow APK/AAB منفصل وفحص `audit:admin`.
- تأكيد أن `free-section` القديم كان شبكة مشاركة محلية دون إنترنت فقط؛ لا يعاد حسب طلب المستخدم.
- جعل قائمة محادثات السوق متوافقة مع مخطط الإنتاج قبل إضافة `listing_snapshot` و`market_transactions`.
- جعل تحديث الرسائل وقائمة السوق خلفياً بعد نجاح إرسال الرسالة حتى لا ينتظر المستخدم إعادة تحميل القائمة.
- إضافة قناة WebRTC صوتية مستقلة لمؤثرات غرفة الأطفال مع تنظيفها عند إنهاء المكالمة.
- منع hard-delete لإعلانات السوق من أدوار العميل في ترحيل المعاملة، وإزالة سياسة `products_delete_own`.
- تحديث CI bootstrap ليحاكي امتياز الحذف القديم واختبار إزالته.
- تحديث cache namespace وجميع اختبارات التوافق والأداء والحقول.
- إعادة الفحوص الساكنة: chat 56، retention/kids/vault 36، UI 244 handler call / 116 function name، prebuild 41 asset، وبقية audits ناجحة.
- محاولة `npm ci` تعثرت بسبب DNS؛ لم ينتج Web build أو APK/AAB.
- لا تغيير في Supabase production، ولا push إلى GitHub، ولا اختبار هاتفين حتى الآن.
