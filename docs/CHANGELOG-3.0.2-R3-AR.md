# سجل تغييرات المرشح Alwaha-Pro 3.0.2 — R3

**التاريخ:** 2 نوفمبر 2026
**مرجع المصدر:** `f116998da546b05b65d52bf89871de1490dcc920`
**الفرع المستهدف:** `alwaha-pro-3.0.2-release-20261102`

## إصلاحات الوظائف

- إشعارات الصداقة: قبول/رفض الطلب لا يمرر النقر إلى البطاقة الأم، يمنع الإرسال المكرر، يزيل الطلب المعالج وحده، ويعلّم إشعاره المرتبط فقط كمقروء.
- السوق: رسائل السوق منفصلة عن رسائل الأصدقاء ولا تشترط الصداقة، لقطة الإعلان تحفظ تفاصيل المنتج، البيع يسجّل عبر RPC ذرية، وحذف الإعلان من واجهة البائع أصبح أرشفة لا حذفاً فورياً.
- المكالمات: إضافة ملف إضافة Android الأصلي المفقود لتوجيه السماعة/السبيكر ومشاركة APK المثبت؛ مسار السوق الصوتي يبقى محصوراً بأطراف المحادثة.
- موجز المنشورات: دمج الطلبات المتزامنة وإضافة حدود زمنية للطلبات البطيئة.
- غرفة الأطفال: غرفة CSS بمنظور 2.5D، صورتان عائمتان muted من فيديو الطرف الآخر دون إنشاء اتصال أو قناة صوت ثانية، فلاتر ألوان، ألعاب قابلة للسحب/لوحة المفاتيح، أصوات متدرجة، مفتاح/باب، focus trap وخروج ولي الأمر.
- الخزنة: تشفير AES-GCM/PBKDF2، تنسيق مضغوط ومتوافق مع ملفات النسخ السابقة، حفظ الملف المشفّر محلياً، تنزيل النسخة المحفوظة، استعادة المسودات والتفضيلات دون مسح كامل IndexedDB، وترقيم صفحات تصدير السجلات السحابية مع تحذيرات الحد.
- المواسم والتنقل: أصوات خفيفة من AudioContext واحد ومعدل زمني يمنع استنزاف الصوت عند سحب الدوائر.

## قواعد البيانات والأمان

- أضيف ترحيل يزيل صلاحيات الكتابة والحذف/TRUNCATE الزائدة عن جداول `likes`, `profiles`, `ratings` القديمة مع إبقاء SELECT.
- أضيف ترحيل يحتفظ بمحادثات السوق 30 يوماً بلا ضمان، ويحفظ سجل البيع حتى انتهاء الضمان +30 يوماً، ويرسل تنبيهاً للمشتري والبائع قبل/عند الاستحقاق، ثم يمنح 7 أيام كاملة بعد الإشعار قبل الحذف حتى إذا عادت مهمة Cron بعد انقطاع طويل، ويستثني المعاملات المتنازع عليها.
- أضيفت اختبارات SQL للامتيازات وسياسة الاحتفاظ، واختبار سلوكي لدورة البيع/الضمان/النزاع.
- تبقى الترحيلات التاريخية غير المطبقة خارج مجلد migrations النشط؛ مصدران قديمان مطبقان في الإنتاج ما زالا مفقودين، ولذلك حارس `supabase-migrations.yml` يمنع أي دفع تلقائي.

## الإطلاق والبناء

- إضافة `audit:ui` و`audit:retention-kids-vault`.
- إضافة Job PostgreSQL 16 مؤقت إلى GitHub Actions؛ يتطلب نجاحه قبل Android build.
- إضافة فحص `npm audit --audit-level=high`، وبناء Web/Android، وتوقيع APK/AAB والتحقق من التوقيع في CI.
- تدقيق إعداد أصول محلية يعتمد على 41 مورداً موجوداً داخل الحزمة.
- إضافة سكربت Termux يزامن شجرة المصدر كاملة إلى فرع إصدار مستقل فقط، ولا يغير `main` ولا قاعدة Supabase.

## ما لم يُعتمد بعد

لا يوجد حتى الآن بناء 3.0.2 أو توقيع APK/AAB أو اختبار هاتفين. لم تُطبق أي migration على قاعدة الإنتاج. وضع الأطفال لا يستخدم تتبع وجه AR أو محرك 3D/WebGL/فيزياء حقيقية. هذه حدود موثقة وليست نجاحات مزعومة.
