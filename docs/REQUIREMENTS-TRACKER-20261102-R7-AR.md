## أشياء غير مطلوبة الاسترجاع

- الشبكة المحلية/mesh share: مستبعد عمداً.
- Bluetooth call control: لم ينفذ؛ لا نضع زرّاً يوهم بأنه يعمل.
- بيانات seller_email / أرقام أو هويات المشترين الخاصة: لا تعاد للواجهة.
- ملفات APK/AAB 3.0.1 build 38/40: مرجع تاريخي فقط، لا تمثل 3.0.2.
- ملفات migrations التاريخية الناقصة: لا تُنشأ تخميناً ولا تُحذف سجلاتها.

## معيار قبول المتطلب

لا يتحول أي بند إلى «مكتمل» لمجرد وجود function أو زر أو migration. يلزم: مسار UI، صلاحية DB/RLS، نجاح الشبكة، حالة خطأ مفهومة، ثم اختبار جهاز مناسب. البنود التي تتعلق بخصوصية/عزل المستخدمين تحتاج اختبار حسابين مستقلين على الأقل.
