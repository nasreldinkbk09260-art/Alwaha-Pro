## 4. تسلسل مرشحات 3.0.2

- R1: المصدر المرشح الأول 3.0.2 بتاريخ 1 نوفمبر.
- R3/R4/R5/R6/R7: نقاط متتالية، وليست مشاريع بديلة. أضافت/جمعت تحسينات النسخة، ومنها صوت غرفة الأطفال عبر مسار `MediaStreamDestination` منفصل، حماية حذف السوق وسجل المعاملة والضمان، إصلاحات صلاحيات أعمدة المنتجات، استعادة native plugin الذي سقط في R5، واختبارات SQL.
- R7.1: تعديل مفكرة واستمرارية، بلا تغيير منطق تطبيق.
- R7.1-PUSHFIX: إصلاح سكربت النقل وتدقيق المسافات، بلا تغيير سلوك التطبيق.
- **R7.3 الحالي:** يتضمن كود R7.1-PUSHFIX، يحدّث cache token، يصلح schema fixture في CI، يضيف اختبار SQL لمحادثة السوق دون صداقة، ويضيف audit reconciliation ويربط فرع البناء.

## 5. غرفة الأطفال — الدليل وحدود التنفيذ

`alwaha-kids-room.js` حزمة محلية ذات مشهد CSS perspective/2.5D؛ تحتوي فلاتر كاميرا، نافذة فيديو للطرف الآخر ونافذة محلية، وجه عائم، بالون، ألعاب قابلة للسحب ولوحة المفاتيح، مفتاح/قفل/باب، تحكم ولي الأمر، restore video DOM، وتفضيل `prefers-reduced-motion`. `index.html` ينشئ `AudioContext.createMediaStreamDestination()` ويضيف track منفصلاً إلى RTCPeerConnection، والجسر `window.alwahaPlayCallEffect` يسمح بوصول مؤثرات الأطفال للطرف الآخر.

الكوب يتحول إلى شظايا كرتونية ويُشغّل صوت زجاج؛ النص داخل الكود يقول صراحة «شظايا كرتونية فقط». هذا ليس محرك فيزياء/زجاجاً واقعياً، وليس AR كاميرا حقيقياً ولا مشهداً ثلاثي الأبعاد هندسياً. العناصر البرمجية موجودة، أما جودة الاتصال/عدم الصدى/الأداء والحرارة فلا تثبت إلا باختبار هاتفين.

## 6. ما استُبعد ولماذا

- شبكة محلية/mesh/free file share: مستبعدة عمداً؛ لا نعيد `free-section` أو عناصرها القديمة.
- Bluetooth call routing: غير منفذ؛ نحتفظ بالنص الصريح ولا نقدم زرّاً وهمياً. السماعة/مكبر الصوت مسار Android منفصل.
- `seller_email` و` sold_to` وأعمدة بيع/أرشفة الحساسة: لا تُكشف لواجهة العميل. استخدم محادثة السوق الداخلية وسجل المعاملة.
- APK/AAB Build #43: مرجع 3.0.1 تاريخي فقط، غير صالح كتسليم 3.0.2.
- Cache marker القديم R2/R5 لا يبقى في نسخة الإصدار الحالية؛ استبدل بـR7.3 namespace مع تعديل جميع الاختبارات.

## 7. النواقص التاريخية التي لا يجوز اختلاقها أو حذفها

- Supabase يسجل migration `20261011184718_alwaha_profile_privacy_clean_start` و`20261011184813_verification_request_profile_requirements` على أنها مطبقة، لكن ملفي SQL الأصليين غير موجودين في الشجرة أو الأرشيفات التي استعيدت حتى الآن. لا ننشئ SQL تخمينياً، ولا نعيد ترقيم/حذف history.
- ثلاثة ملفات migrations بأسمائها الأصلية محفوظة في `docs/migration-archive-unapplied/` لأنها تمثل تاريخاً موازياً/مكرراً لتوقيتات مطبقة تحت أسماء/إصدارات live مختلفة؛ لا تنقلها إلى مجلد migrations النشط قبل مطابقة النسخة مع سجل Supabase.
- الملفات القديمة 2.8.2/2.8.4/2.8.7/2.8.8 موجودة في حزمة المراجع التاريخية، وليست قاعدة build الحالية. لم يظهر مصدر 2.8.5/2.8.6 منفصلاً في الأرشيف المتاح، لكن تم فحص commits/metadata والنسخ اللاحقة المتاحة.

## 8. الحكم النهائي

**نعم، R7.3 يجمع آخر إصلاحات 3.0.1 المتاحة مع المصدر التراكمي 3.0.2 حتى R7، ويضيف اختبارات حماية/مصالحة إضافية.** لا يعني هذا أن الإطلاق الرسمي مكتمل: الفرع لم يُرفع بعد، ولم يعمل GitHub Actions على R7.3، ولم يُنشأ build 3.0.2، ولم تطبق migrations الإنتاجية، ولم تُختبر المكالمات/السوق/الأطفال على جهازين. تُسجل هذه كبوابات واضحة بدلاً من الادعاء بأنها أغلقت.


### تحديث R7.3 — المشاهد الموسمية
استُبدل تلوين الموسم البسيط بأربع لوحات خلفية كاملة الشاشة معرفة محلياً بـCSS (سماء/أفق/وهج وطبقات ضوء) مع حركة بطيئة جداً. لا تتطلب تنزيل صور إضافية أو Canvas. تتوقف الطبقات المتحركة عند `prefers-reduced-motion` أو وضع توفير البيانات. بقي اختبار المظهر والقص والتباين على الهواتف اختباراً ميدانياً مطلوباً.

### تحديث R7.3 — دوائر التنقل المرحة
أضيف تابع بصري خفيف بعد السحب: شخصيتان Emoji تمشيان معاً، وتسقط قبعة/حذاء ثم يعودان في الحركة نفسها، مع اختلاف نغمة الصوت حسب مسافة إعادة الترتيب. لا يظهر المؤثر عند تقليل الحركة أو توفير البيانات. هذا تأثير كرتوني صغير وليس نموذج شخصيات ثلاثي الأبعاد.


### تحديث R7.3 — فهرس رسائل السوق
أُضيف فهرس `market_messages(sender_id)` إلى migration السوق/الأرشفة غير المطبقة، وأضيف assertion في اختبار SQL الجديد للتأكد من وجوده. هذا يعالج تنبيه advisor المحدد حول المفتاح الخارجي دون حذف الفهارس الأخرى التي ظهرت غير مستخدمة.
