# نظام المظاهر R7.5

## الاختيارات
- **الأساسي الأصلي:** يعود إلى مظهر الواحة المعتمد سابقاً.
- **الربيع:** مشهد بحيرة وأشجار مزهرة؛ لوحة وردية/نعناعية.
- **الصيف:** شاطئ ونخيل ومياه فيروزية؛ لوحة تركواز/ذهبية.
- **الخريف:** غابة وأوراق ذهبية؛ لوحة كهرمانية/نحاسية.
- **الشتاء:** جبال ثلجية وأشجار صنوبر؛ لوحة جليدية/زرقاء.

## السلوك
- تتغير الخلفية وطبقة القراءة والبطاقات والنوافذ وحقول الإدخال وحدود الأزرار وألوان شريط التنقل وفق متغيرات CSS موحدة.
- الخلفيات محلية ومسبقة التخزين في Service Worker؛ لا تعتمد على تحميل صور من الإنترنت.
- الاختيار يحفظ في `localStorage.alwaha_theme`، وهو ضمن مفاتيح تفضيلات الخزنة الموجودة.
- المستخدم الذي لديه قيم قديمة `nature` أو `tech` أو `soft` تتم ترقيتها تلقائياً إلى `spring` أو `summer` أو `winter`.
- اختيار `default` يخفي طبقة الصور ويعيد الخلفية الأصلية.
- تم احترام تقليل الحركة؛ لا توجد حركة مستمرة فوق الخلفيات.

## الملفات
- `alwaha-theme-system.css` لوحات الألوان وقواعد العرض.
- `assets/backgrounds/bg-{spring,summer,autumn,winter}.webp` خلفيات شاشة الهاتف 1200×1920.
- ملفات SVG المقابلة هي مصادر الرسوم الأصلية.

ملاحظة النقل بين الأجهزة: ملفات الخلفيات نفسها مضمّنة في نسخة التطبيق، لذلك كل تثبيت جديد يحصل على المشاهد الأربعة محلياً دون إنترنت. اختيار الثيم هو تفضيل شخصي محفوظ محلياً، وينتقل إلى الجهاز الآخر عند تصدير النسخة الاحتياطية المشفرة واستعادتها؛ مشاركة APK وحده لا تنقل بيانات المستخدم أو إعداداته الخاصة.
