# نقطة الاستمرارية — Alwaha-Pro 3.0.2 R7.4.2 — 3 نوفمبر 2026

- **المصدر:** استمرار من R7.4.1 على فرع R7.4 نفسه؛ لا إعادة بناء من 2.8.x ولا إنشاء تطبيق جديد.
- **هوية التطبيق:** `pro.alwaha.app`، الاسم `Alwaha-Pro`، الإصدار `3.0.2`.
- **العيب الحرج:** حلقة MutationObserver/`syncDock` التي حبست خيط الواجهة.
- **الإصلاح:** مراقبة طبقات النوافذ فقط، تحديث مقبض التنقل عند تغير النص، قصر مراقب التنقل على body class، ومزامنة النوافذ بإطار رسم واحد.
- **الثيمات:** الأساسي الأصلي + الربيع + الصيف + الخريف + الشتاء؛ صور محلية مضمنة في الحزمة ومسبقة التخزين.
- **استبعاد مقصود:** زر الشبكة المحلية لا يعاد، ولا تطبق أي migrations على قاعدة الإنتاج.
- **متبقي:** CI على R7.4.2، فحص APK/AAB والتوقيع ومعرف التطبيق، وتجربة هاتفين على فتح التطبيق والتنقل والصفحات والمكالمات والسوق والنسخ الاحتياطي.
- **السلامة:** لا تحذف التطبيق المثبت ولا تمسح بياناته. التراجع يكون فقط بحزمة موقعة بنفس المفتاح وversionCode أعلى، أو تثبيت نسخة قديمة بعد نسخة احتياطية واعية.

## نتائج الجولة الساكنة الأخيرة

اجتازت `audit:release`, `audit:performance`, `audit:field-repair`, `audit:chat`, `audit:compatibility`, `audit:native-call-ui`, `audit:ui`, `audit:retention-kids-vault`, `audit:admin`, `audit:marketplace-columns`, `audit:reconciliation`, `audit:fullscreen-ui`, `audit:runtime`, `audit:themes`، وكذلك `node --check` لكل JS/MJS والكتل المضمنة، و`bash -n` لسكربت الرفع.

لم يكتمل `npm ci` داخل حاوية المراجعة بسبب مهلة npm registry؛ لا يوجد Web/Android build محلي ولا اختبار جهازين. فرع R7.4.2 لم يُرفع بعد. الخطوة التالية هي سكربت Termux المرفق ثم GitHub Actions.
