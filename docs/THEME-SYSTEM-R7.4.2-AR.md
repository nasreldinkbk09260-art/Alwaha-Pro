# نظام الثيمات المدمج في R7.4.2

- المظهر الافتراضي الأصلي محفوظ؛ قواعد لوحة الألوان الموسمية لا تفرض ألواناً جديدة على الثيم الأساسي.
- أربعة ثيمات كاملة: الربيع، الصيف، الخريف، الشتاء.
- الصور المضمّنة محلياً بدقة 1200×1920 WebP، مع ملفات SVG المصدر.
- ملف `alwaha-theme-system.css` يربط ألوان النصوص والبطاقات والحقول والنوافذ والأزرار مع الخلفية المختارة.
- ملفات CSS والصور تدخل بناء Web وذاكرة Service Worker المسبقة، ولا تحتاج اتصال إنترنت بعد التثبيت.
- اختيارات الإصدارات القديمة `nature/tech/soft` تتحول إلى الربيع/الصيف/الشتاء دون مسح التفضيل.
- مشاركة APK وحده تنقل البرنامج والأصول، لكنها لا تنقل إعدادات المستخدم المحلية؛ نقل الإعدادات يتم عبر النسخة الاحتياطية.
