## الأزرار التي لم نكررها

المصدر يحتوي بالفعل على:
- زر تسجيل/إرسال الرسائل الصوتية في المحادثة المباشرة والسوق.
- زر اختيار صورة/فيديو في المحادثة المباشرة والسوق.
- زر اتصال صوتي بالبائع عبر محادثة سوق خاصة بالمشاركين.

المشكلة السابقة قد تكون من نسخة APK أقدم أو cache قديم أو اختبار تكامل، لذلك أضيفت فحوص واجهة. لا تعتبر هذه العناصر مثبتة على هاتف المستخدم حتى يصدر APK جديد ويتم تثبيته واختباره.

## حدود يجب أن تبقى معلنة

1. **Bluetooth:** الاكتشاف فقط؛ لا يوجد BLE GATT أو RFCOMM لنقل الرسائل والملفات بعد.
2. **Wi-Fi mesh:** التمرير المشفر موجود، والتمرير التلقائي يبدأ بعد مصافحة جار موثوق متصل. اكتشاف الطوبولوجيا والمسارات بشكل تلقائي/مبني على المسافة غير مكتمل.
3. **المكالمات المحلية:** يمكن تمرير إشارات WebRTC المشفرة، لكن الصوت/الفيديو الحي لا يُرحّل عبر عدة أجهزة.
4. **إضافة مشارك/مكالمة جماعية:** غير منفذة. مدير المكالمات الحالي يتعامل مع طرف بعيد واحد واتصال واحد. لا تضف زرّاً شكلياً قبل بناء وإقرار multi-peer signaling وإدارة الأعضاء والتنظيف والصلاحيات.
5. **عدم الاتصال:** توجد نسخ مشفرة لبعض الملف الشخصي والمحادثات التي سبق فتحها ونسخ عامة محدودة. ليست نسخة كاملة لكل الأقسام أو الحساب. لا تتجاوز التحقق من الجلسة المحلية أو تعرض بيانات مستخدم آخر لتلبية شرط «لا تطلب تسجيل الدخول».
6. **بيانات الهاتف:** Android لا يتيح للتطبيق العادي إطفاء بيانات الهاتف بصمت؛ زر الإعدادات يفتح لوحة النظام ليبدّل المستخدم الشبكة بنفسه.
7. **اختبار الهاتفين:** لا يوجد حتى الآن إثبات فعلي لرسائل السوق/الصوت/الفيديو/الشبكة المحلية أو غرفة الأطفال على هاتفين حقيقيين.

## نتائج CI المسجلة

- #851/#853/#854 فشلت في تجهيز/صياغة اختبار aggregate view أو في توقع سياسة عامة لا تطابق إنتاج التعليقات؛ لم تُثبت فشل الإنتاج.
- #860: اختبار PostgreSQL المؤقت نجح بعد مواءمة fixture مع سياسة التعليقات العامة ودور CI المقيّد. أُلغي build Android عندما وصل تحديث لاحق.
- #862: وظيفة SQL المؤقتة نجحت؛ وظيفة Android أُلغيت عند دفع تحديث المصدر التالي.
- تم تعديل تدقيق الأداء لإزالة قائمة فروع ثابتة. تحقق من أحدث Actions بعد HEAD الحالي قبل متابعة البناء.

## ضوابط العمل والاستئناف

1. تابع على هذا الفرع فقط: `alwaha-pro-3.0.4-user-requests-20261120`.
2. افحص HEAD ونتائج Actions أولاً، ولا تفترض نجاح تشغيل ملغى.
3. شغّل جميع audits وSQL CI وبناء APK/AAB، ثم اربط artifact بالـcommit والشهادة والبصمة.
4. لا تنشر إلى `main` أو Pages أو Release. النشر يتطلب `main` و`ALWAHA_PUBLIC_RELEASE_ENABLED=true` وموافقة صريحة.
5. لا تطبق migration العدادات على Supabase الإنتاجية في هذه الدفعة.
6. بعد البناء، ثبّت على هاتفين Android واختبر الأزرار والاتصال المحلي/الإنترنت وغرفة الأطفال، وسجل النتائج الفعلية منفصلة عن CI.
