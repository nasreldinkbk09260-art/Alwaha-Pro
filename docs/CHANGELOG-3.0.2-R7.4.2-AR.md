# سجل R7.4.2 — إصلاح تجمّد Android WebView ودمج الثيمات — 3 نوفمبر 2026

- استمرار من R7.4.1؛ تم الحفاظ على جميع ملفات المشروع والهوية والإصلاحات السابقة.
- إصلاح حلقة MutationObserver: كانت مزامنة النوافذ تعيد مزامنة دوائر التنقل عند كل تغيير DOM، ومزامنة الدوائر تعيد كتابة نص المقبض في كل مرة، فتنتج تغييرات DOM بلا نهاية.
- جعل تحديث نص المقبض مشروطاً بتغير النص، وحصر مراقب التنقل في تغيّر class على body فقط.
- حصر مراقب النوافذ في تغييرات طبقات النوافذ ودمج تحديثاته في requestAnimationFrame؛ مزامنة الدوائر عند تغير النافذة العليا فقط.
- دمج ثيم أساسي يحافظ على المظهر الأصلي وأربعة ثيمات موسمية بخلفيات WebP محلية 1200×1920.
- إضافة CSS موحد للألوان والبطاقات والحقول والنوافذ وعناصر التنقل، مع بقاء الثيم الأساسي دون فرض ألوان موسمية.
- إدراج CSS والصور في بناء Web وService Worker، وإضافة اختبار runtime للثيمات واختبار رجعي لحلقة المراقب.
- تغيير Cache namespace إلى `alwaha-pro-v3.0.2-r7.4.2-modal-observer-loop-fix-20261103`.
