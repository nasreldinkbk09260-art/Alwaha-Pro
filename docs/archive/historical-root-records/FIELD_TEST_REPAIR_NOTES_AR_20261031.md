# مذكرة إصلاح ملاحظات الاختبار الميداني — Alwaha-Pro 3.0.1

**التاريخ:** 31 أكتوبر 2026

## الإصلاحات المضافة
1. أضيف مكوّن Android أصلي يختار سماعة المكالمات افتراضياً، مع زر اختياري لمكبر الهاتف، ويعيد إعدادات الصوت عند إنهاء المكالمة. Android 12+ يستخدم اختيار جهاز الاتصال، والإصدارات الأقدم تستخدم وضع الاتصال ومفتاح مكبر الصوت.
2. أضيفت حدود viewport وبدائل CSS لغرف الألعاب حتى لا تخرج النافذة عن الشاشة في WebView الأقدم.
3. حُذف قسم مشاركة الملفات/اختيار الملف القديم ووظيفته ورسائله المضللة. بقيت مشاركة محتوى الدردشة والمنشورات والريلز ومشاركة التطبيق.
4. أصبح مركز التنبيهات متاحاً من شريط التنقل في جميع الأقسام، مع عداد غير المقروء واشتراك Realtime لطلبات الصداقة الواردة. بقيت أزرار قبول/رفض طلبات الصداقة.
5. أصبح زر مشاركة التطبيق ظاهراً؛ في APK الأصلي ينسخ ملف APK المثبت إلى cache آمن ويعرض قائمة Android لمشاركته عبر SHAREit/بلوتوث/التطبيقات المتاحة. في نسخة الويب يشارك الرابط.

## الحد المتبقي: الاتصال بعد إنهاء التطبيق
دعوات المكالمات الحالية تعتمد على Supabase Realtime داخل صفحة التطبيق. لا يبقى الاشتراك فعالاً بعد إنهاء عملية التطبيق؛ لذلك **هذه الحزمة لا تدعي إظهار شاشة المكالمة بعد force-stop أو إغلاق العملية بالكامل**.

يتطلب ذلك FCM، وبيانات اعتماد خادمية محفوظة خارج المستودع، وإرسال push عند طلب المكالمة، ثم إشعار/نشاط Android أصلي بأزرار قبول ورفض وإعدادات الشاشة الكاملة المناسبة لإصدار Android. إعدادات Firebase/FCM غير موجودة حالياً؛ لم نضف أسراراً أو خدمة وهمية ولم نغير قاعدة الإنتاج.

## اختبارات ما بعد البناء
- بناء Android/Java عبر GitHub Actions.
- اختبار سماعة المكالمات الافتراضية وزر المكبر والعودة للسماعة على هاتف حديث وOPPO A5s Android 7.
- اختبار غرف الألعاب على شاشة صغيرة وكبيرة.
- إرسال طلب صداقة والجهاز المستقبل مفتوح والتحقق من العداد والقبول/الرفض.
- اختبار إغلاق العملية بالقوة منفصلاً؛ استقبال المكالمة بعد force-stop يظل معلقاً حتى إضافة FCM والإشعار الأصلي.

**الحالة:** إصلاحات مرشحة للبناء والاختبار، وليست إصداراً نهائياً قبل نجاح CI والاختبارات الفعلية.
