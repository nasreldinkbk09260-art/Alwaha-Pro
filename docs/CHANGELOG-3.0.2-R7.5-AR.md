# سجل تحديث 3.0.2 R7.5 — الثيمات الموسمية الكاملة

- الإبقاء على المظهر الأساسي الافتراضي الأصلي دون إعادة تصميم قسري.
- إضافة أربعة مشاهد محلية أصلية بنسبة 1200×1920: الربيع، الصيف، الخريف، الشتاء.
- ربط كل مشهد بلوحة ألوان متناسقة للبطاقات والنوافذ وعناصر التنقل والحقول والحدود والتأكيدات.
- إضافة ملفات CSS والصور إلى بناء Web وذاكرة الخدمة المسبقة كي تعمل دون اتصال بعد تثبيت التطبيق.
- تضمين الاختيار في `alwaha_theme` الموجود في تفضيلات الخزنة المحلية والنسخة الاحتياطية.
- ترحيل اختيارات المستخدم القديمة `nature/tech/soft` إلى الثيمات الموسمية الجديدة دون فقد التفضيل.
- لم تُعدّل هوية التطبيق أو قاعدة الإنتاج أو سياسات السوق.

## ملاحظة فنية

الخلفيات رسوم مناظر أصلية بأسلوب توضيحي رقمي، وليست صور فوتوغرافية. أبعادها 1200×1920 WebP مضغوطة للاستخدام المحلي، مع ملفات SVG المصدر.
