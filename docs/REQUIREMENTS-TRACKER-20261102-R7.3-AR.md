## القرار

R7.3 هي نقطة الاستمرار الوحيدة. لا نعود لرقعة 3.0.1 كقاعدة، ولا نعيد الفحوص نفسها في Termux. GitHub Actions بعد الرفع يعيد تدقيق CI/SQL والبناء باعتباره بوابة مستقلة، ثم التجربة اليدوية على جهازين. لا يُسمّى الإصدار رسمياً قبل نجاح جميع البنود التي تتطلب إنتاجاً أو جهازاً حقيقياً.
