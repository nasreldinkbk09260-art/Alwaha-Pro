# Alwaha Admin 1.0.0 — لوحة إدارة الواحة

## الهوية والبناء
- تطبيق عربي مستقل باسم «إدارة الواحة».
- Android package: `pro.alwaha.admin`؛ منفصل عن التطبيق العام `pro.alwaha.app`.
- آخر بناء موثق قبل إضافة صندوق الدعم: Admin Build #22. هذا التحديث يطلب بناءً جديدًا للتحقق من واجهة الدعم.
- نتيجة البناء السابق: https://github.com/nasreldinkbk09260-art/Alwaha-Pro/actions/runs/44182463750

## وظائف الخادم الحالية
Edge Function `admin-api`: ACTIVE، version 8، `verify_jwt=true`.

الإجراءات المتاحة:
- `summary`
- `list_users`
- `list_verification_requests`
- `review_verification`
- `list_content_reports`
- `review_content_report`
- `list_support_tickets`
- `review_support_ticket`
- `list_audit_logs`
- `purge_test_media`
- `get_management_config`
- `save_management_config`

الواجهة تعرض الملخص والحسابات والبحث وطلبات التوثيق والبلاغات وسجل التدقيق وصندوق «دعم المستخدمين». تبويب «الخطط والحصص ووسائل الدفع» يوفّر محرراً مرئياً لنطاق السوق المجاني وحصص الرسائل اليومية/الأسبوعية وتجهيز خطتي Plus وPremium وطرق الدفع اليدوية الأربعة المعروفة، مع محرر JSON متقدم. جميع التغييرات تمر عبر `admin-api` وتُسجّل في سجل التدقيق.

## استقبال الشكاوى والخصوصية
- نموذج الشكوى داخل التطبيق نصّي فقط؛ لا يرفع صورًا أو مرفقات ولا يقرأ المحادثات الخاصة.
- جدول `support_tickets` عليه RLS، ولا توجد صلاحيات مباشرة لـanon/authenticated؛ الوصول يتم عبر Edge Functions فقط.
- يُتحقق من جلسة صاحب البلاغ، وتُحدّ الطلبات، وتُنظّف بيانات الاتصال والرموز السرية الشائعة قبل التخزين.
- صاحب البلاغ يرى طلباته وحالتها فقط؛ لوحة الإدارة تتطلب تحقق `is_admin` على الخادم.
- الفرز الحالي قواعد ثابتة محدودة، وليس موظف ذكاء اصطناعي متصلًا بمزوّد خارجي. لا توجد إصلاحات تلقائية أو حذف أو حظر آلي.

## حماية الخادم
- يتحقق Edge Function من JWT عبر `auth.getUser(token)` ثم يقرأ `public.users.is_admin` على الخادم باستخدام Service Role.
- قائمة الإجراءات محددة ومقفلة، مع حدود للصفحات والبحث وحجم الطلب.
- يُسجّل الإجراء في `admin_action_logs` بحالة pending ثم تُحدّث النتيجة إلى success/denied/error.
- لا يوجد مفتاح `service_role` في المتصفح أو APK.

## حدود اللوحة الحالية
هذه لوحة إدارة أساسية وليست مكتبًا متعدد الموظفين كامل الصلاحيات. لا توفر حاليًا:
- أدوار موظفين متعددة بصلاحيات دقيقة.
- مساعد AI خارجي أو عمال AI مستقلين لإصلاح الكود تلقائيًا.
- إدارة شاملة للنزاعات والضمان والمعاملات أو أدوات حظر/حذف حسابات من الواجهة.
- تنبيهات دفع فورية مغلقة التطبيق لبلاغ جديد.

أي إجراء إداري جديد يجب أن يُنفذ عبر Edge Function محمية، مع تحقق خادمي من الصلاحية والهدف، وسبب موثق وسجل تدقيق واختبارات رفض لغير المصرح لهم. لا تُعرض أزرار توحي بوظيفة غير منفذة.
